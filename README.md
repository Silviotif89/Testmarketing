# Marketing Career Lab

Aplicación web interactiva de orientación vocacional para estudiantes de Marketing.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y este archivo a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, la carpeta `/ (root)` y guarda.

La aplicación no requiere instalación, backend, base de datos ni claves API.

## Uso local

Abre `index.html` directamente en un navegador moderno.
